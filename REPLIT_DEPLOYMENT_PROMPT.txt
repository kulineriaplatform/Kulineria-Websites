================================================================================
TASK 2: SETUP BACKEND LARAVEL
================================================================================

Steps:

1. Navigate to backend directory:
   cd backend

2. Install Composer dependencies:
   composer install

3. Generate APP_KEY (if not already generated):
   php artisan key:generate

4. Clear cache configuration:
   php artisan config:clear
   php artisan cache:clear

5. Run database migrations:
   php artisan migrate --force

6. Setup storage symbolic link:
   php artisan storage:link

7. Start Laravel server on port 8000:
   php artisan serve --host=0.0.0.0 --port=8000

NOTES:
- Ensure port 8000 is not used by other applications
- Server must run in background for Task 3
- Do not stop this process until frontend is also running

================================================================================
TASK 3: SETUP FRONTEND NEXT.JS
================================================================================

File Location: /.env.local (in root project, not in backend)

Configuration to be created:

NEXT_PUBLIC_API_URL=https://[REPLIT_DOMAIN].repl.co/api
NEXT_PUBLIC_APP_NAME="Kuliner Nusantara"

Steps:

1. From backend directory, return to root project:
   cd ../

2. Install npm/pnpm dependencies:
   pnpm install
   (or: npm install)

3. Build Next.js application:
   npm run build
   (or: pnpm build)

4. Start Next.js server on port 3000:
   npm run start -- -p 3000
   (or: pnpm start -- -p 3000)

NOTES:
- Task 2 (Laravel) must already be running before Task 3
- Both servers must run simultaneously
- Port 3000 is the default for Next.js

================================================================================
TASK 4: CONFIGURE REPLIT
================================================================================

Create/Update the following files in root project:

File Name: replit.nix
Content:

{ pkgs }: {
    deps = [
        pkgs.php
        pkgs.nodejs
        pkgs.mysql
        pkgs.composer
        pkgs.pnpm
    ];
    
    env = {
        REPLIT_ENTRYPOINT = "start-server.sh";
    };
}

---

File Name: start-server.sh
Content:

#!/bin/bash

# Start Laravel Backend
cd backend
php artisan serve --host=0.0.0.0 --port=8000 &
BACKEND_PID=$!

# Start Next.js Frontend
cd ../
npm run start -- -p 3000 &
FRONTEND_PID=$!

# Wait for both processes
wait $BACKEND_PID $FRONTEND_PID

---

TIPS & TROUBLESHOOTING
================================================================================

1. PORT CONFLICT:
   - If port 8000 or 3000 is already in use, change in command
   - Example: php artisan serve --host=0.0.0.0 --port=8001

2. DATABASE CONNECTION ERROR:
   - Test connection: php artisan tinker
   - In tinker: DB::connection()->getPdo(); (if fails, config error)
   - Verify credentials in .env

3. CORS ERROR:
   - Update CORS_ALLOWED_ORIGINS in .env
   - Ensure SANCTUM_STATEFUL_DOMAINS matches Replit domain
   - Restart server after updating .env

4. SLOW FIRST LOAD (Free Plan):
   - Normal behavior for free plan
   - Replit server is "waking up"
   - Install UptimeRobot for keep-alive (workaround for free plan)

5. MISSING DEPENDENCIES:
   - Backend: composer install
   - Frontend: npm install or pnpm install
   - Ensure all dependencies are installed before running

6. STORAGE PERMISSION:
   - Run: php artisan storage:link
   - Ensure storage/ directory is writable

7. CACHE ISSUES:
   - Clear all cache: php artisan optimize:clear
   - Rebuild frontend: npm run build
